# ConcursosPro

App de estudos para concursos, com trilha adaptativa e caderno de erros.

## TCESP 2026

Trilha dedicada ao concurso para Auditor de Controle Externo – DIPE, Edital 001/2026, VUNESP. O MVP inclui questões, correção comentada, caderno de erros e dados estruturais do edital.

## Publicação

Este projeto é uma PWA estática e pode ser publicado pelo GitHub Pages. No repositório: **Settings → Pages → Deploy from a branch → main → / (root)**.

URL esperada: `https://joaopedropontes95.github.io/App_concursosPRO/`
